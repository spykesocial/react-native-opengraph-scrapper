- **ESLint crash "expand is not a function" in minimatch**: The resolution `"brace-expansion": "5.0.9"` in package.json resolutions forces brace-expansion 5.x onto minimatch 3.x which expects 1.x API. FIX: Remove the GENERAL `"brace-expansion"` resolution and only keep the SCOPED one (`"@typescript-eslint/typescript-estree/minimatch/brace-expansion"`). minimatch 3.x needs brace-expansion 1.x.
- **"Multiple bundler flags set: TURBOPACK=1, --webpack"**: The engine now strips TURBOPACK from the environment automatically. If you still see this error, run the build with `TURBOPACK= yarn build:fast` or `unset TURBOPACK && yarn build:fast`. Do NOT try `TURBOPACK=0` — Next.js treats any value as truthy. Just unset it or set it to empty.
- **ESLint crash in general**: Read the stack trace. Usually a transitive dep version conflict. Pin the dep in resolutions.
- **TypeScript errors**: Read each error, understand what changed, fix the types. Update type imports, add missing types, fix generics.
- **Module not found / can't resolve**: The update may have renamed or removed exports. Find the new import path or use an alternative package.
- **Peer dependency errors**: Add missing peers to resolutions or devDependencies. Or override the peer requirement.
- **Circular dependency / runtime errors**: Check if the update changed module structure. Adjust imports accordingly.
- **Post-build script failures**: These are often deploy/CDN scripts that fail in temp envs — not your problem, but note them.
- **"ENOTFOUND undefined" or "fetch failed" during static generation/build**: The project needs environment variables to build (API keys, store domains, database URLs). Check if `.env.local` exists with the required values. If the env vars are missing and the build fails on external API calls, make the code handle missing env vars gracefully — return empty arrays from generateStaticParams(), wrap data fetching in try/catch, or export `dynamic = 'force-dynamic'` to skip static generation.
- **Any other error**: Read it, understand it, fix it. Search the codebase, read docs, check changelogs if needed.
